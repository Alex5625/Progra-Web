# 🏨 Hotel Las Canarias

Sitio web estático, responsivo y moderno desarrollado para la evaluación del curso **Taller de Programación Web** de la Universidad de Talca. 

El proyecto consiste en la *Landing Page* de un hotel ficticio ("Hotel Las Canarias"), que incluye un carrusel de imágenes, galería interactiva, visualización de habitaciones mediante modales y un formulario de reserva con validación visual.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica del sitio.
* **CSS3:** Estilos personalizados y animaciones (efectos hover).
* **Bootstrap 5.3:** Sistema de grilla, componentes responsivos (Navbar, Cards, Modales, Carrusel) y validación de formularios.
* **JavaScript:** Script nativo de Bootstrap para la interactividad y validación visual del DOM.

## 💻 Instrucciones para visualizar el sitio

### Ejecución local
Si prefieres ver el código fuente y ejecutar el sitio en tu propia máquina, sigue estos pasos:

1. Clona este repositorio en tu terminal usando:
   ```bash
   git clone [https://github.com/Alex5625/Progra-Web](https://github.com/Alex5625/Progra-Web)  
2. Alternativamente, puedes descargar el código en formato ZIP desde el botón verde "Code" en la página principal del repositorio en GitHub.

3. Descomprime el archivo y abre la carpeta del proyecto.

4. Haz doble clic en el archivo index.html para abrirlo en tu navegador web predeterminado. No se requiere instalación de dependencias ni servidores locales.
